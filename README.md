# 機動戰士對決 ONLINE — MS VS (First-Person)

第一人稱 3D 機體對戰網頁遊戲：在大地上鎖定、追蹤、擊墜對手。純 HTML / CSS / JavaScript（Canvas 2D + 自製透視投影），**零依賴、零建置、可直接放 GitHub Pages**。

A zero-dependency first-person mech arena shooter that runs straight from static files.

## 玩法

- **1P 對 CPU**：選機 → 戰鬥 → 戰績 → 再戰／更換機體。
- **大地圖 4000×4000**：中央要塞、斜向大樓、四角高塔、外圈短牆與低掩體。障礙物會擋子彈、擋視線，必須繞位抓開口攻擊。
- **鎖定追蹤**：視角朝向對手 26° 內且視線通透時出現紅色鎖定框（含距離與血條），準星變紅，射擊自動帶提前量。
- **99 秒計時**：KO 或時間到時以剩餘血量比例判定勝負。
- **6 台機體**，各有數值差異與專屬必殺：

| 機體 | 特色 | 必殺 |
|---|---|---|
| 原初型 V-78 | 攻守均衡 | 全彈齊射（7 發扇形） |
| 野戰型 Z-01 | 厚甲近戰、機槍連發 | 熱能斧迴旋（突進多段斬） |
| 冰原狙擊型 I-04 | 遠距高傷 | 超長程陽電子狙擊（會被建築擋下） |
| 沙漠強襲型 S-09 | 最高跳躍與推進 | 追蹤飛彈群 |
| 暗影型 D-13 | 最快、低甲 | 瞬身斬（瞬移背襲） |
| 重裝型 H-77 | 1300 耐久、重砲 | 火力全開·砲擊陣列 |

## 操作

| | 桌機 | 手機 |
|---|---|---|
| 視角 | 滑鼠（點畫面鎖定游標，`Esc` 解除；未鎖定可拖曳） | 右半畫面拖曳 |
| 移動 | `W A S D`／方向鍵 | 左下虛擬搖桿 |
| 跳躍 / 衝刺 | `空白鍵` / `Shift` | `跳` / `衝` 按鈕 |
| 射擊 | 左鍵 或 `J` | `射` |
| 光束刀 | 右鍵 或 `K` | `斬` |
| 必殺 | `L`（氣滿發光） | `必殺` |

建議橫置手機遊玩。右上角可靜音。

## 本地執行

因為使用 ES Module，**必須經由 HTTP 開啟**（直接雙擊 `index.html` 會被瀏覽器的 CORS 政策擋下）：

```bash
# 任選一種
python3 -m http.server 3000
npx serve .
php -S localhost:3000
```

然後打開 <http://localhost:3000>。

## 部署到 GitHub Pages

1. 建立 GitHub 倉庫並把本目錄所有檔案推上去。
2. 倉庫 **Settings → Pages → Source** 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後就會有 `https://<你的帳號>.github.io/<倉庫名>/` 網址。

沒有任何建置流程，`index.html` 就是入口。

## 檔案結構

```
index.html      # 頁面骨架：選機畫面、戰鬥畫面、戰績畫面
style.css       # 全部樣式，含觸控按鈕與安全區域
js/
  units.js      # 全域世界參數與 6 台機體數值
  audio.js      # WebAudio 即時合成音效（無素材檔）
  render.js     # 2D 繪圖工具、機體造型、選機畫面預覽
  render3d.js   # 第一人稱場景：透視投影、障礙物、彈道、HUD、雷達、準星
  game.js       # 戰鬥核心：物理、碰撞、攻擊、鎖定、AI、鏡頭
  main.js       # 畫面切換、鍵盤／滑鼠／觸控輸入
```

## 技術重點

- Canvas 2D 手寫透視投影（`toCam` + 近平面裁切），不引入 three.js 或任何套件。
- 3D 座標：`x` 向右、`z` 向前、`y` 向上，`y = 0` 為地面。
- 障礙物用 AABB 推擠，子彈用 AABB 命中，視線用 2D 線段與 AABB 求交。
- AI 為狀態機：依距離與視線切換接近／游走／後撤／近戰，反應時間 0.1–0.24 秒，命中誤差隨距離放大，會閃彈與抓時機放必殺。
- 音效全部由 WebAudio 振盪器與噪聲即時合成。
